# Chichecipes 🐱

A cosy book of recipes written on paper. Open `index.html` (no build step) or host it on GitHub Pages.

- Pick a small folded card from the 2‑column shelf – it unfolds into a full page while the cauldron's fire is lit. All art is pixel art drawn in code (`sprites.js`).
- Tap an ingredient to cross it off with a quill from its inkwell (tap again to undo). Ticks and scale are remembered per recipe.
- Scale any recipe with the slider, or type any multiplier.

## Adding a recipe
Add an entry to `recipes.js` (field docs at the top of that file). It appears on the shelf automatically.
